1. Terrain slope (Weight 22%)

1.1 What you see

  • Factor bar labelled Terrain slope with score 0–10
  • Value line: e.g. 8.4° or n/a
  • Note if steep: "Steep grade — pad grading / retention likely costly."
  • Source tag: Live · Open-Meteo DEM

1.2 What we fetch

  • Open-Meteo Elevation API → Copernicus DEM ~30 m
  • 5 sample points: centre pad + North / South / East / West at 0.0012° (~133 m)

1.3 What we calculate

  • For each offset point: run distance (m) from centre
  • Rise = |elevation offset − elevation centre|
  • Angle = atan(rise / run) × 180/π
  • Output slope = maximum angle among 4 directions

1.4 Score calculation

Slope (°)Score
≤ 5°10 (best)
≥ 18°0 (worst)
BetweenLinear: (18 − slope) / (18 − 5) × 10
Missing5 (neutral)

1.5 Contribution to final score

Contrib = factor score × 0.22

2. Road access (Weight 14%)

2.1 What you see

  • Factor bar: Road access
  • Value: e.g. 1.24 km or live lookup failed
  • Map: orange marker at nearest road snap point
  • Source: Live · OSRM nearest road

2.2 What we fetch

  • OSRM Nearest API: router.project-osrm.org/nearest/v1/driving
  • Snaps pad to nearest drivable OSM road segment

2.3 What we calculate

  • Road distance (km) = OSRM waypoint distance (m) ÷ 1000
  • Fallback: Haversine pad → snap lat/lon if OSRM distance missing
  • Stores snap coordinates for map overlay

3. Water / flood buffer (Weight 14%)

3.1 What you see

  • Factor bar: Water / flood buffer
  • Value: e.g. 2.15 km, > 8 km, or fallback warning in note
  • Source: Live · OSM Overpass water or Fallback · Photon geocode

3.2 What we fetch

  • Primary: OSM Overpass within 8 km — natural=water, waterway, reservoir, basin

3.3 What we calculate

  • If none found within search radius → report as > 8 km
  • Cap used in scoring at 8 km max

5. Power connectivity (Weight 10%)

5.1 What you see

  • Factor bar: Power connectivity
  • Value: e.g. Tower ABC · 1.2 km or none within 8 km
  • Power panel: nearest tower / line / pole / substation list
  • Map: grid asset markers, connection lines (straight + road route)

5.2 What we fetch (merged TAMS + OSM)

  • TAMS GIS: towers, substations, transmission lines
  • OSM Overpass: tower, portal, pole (≤15 km radius), line, cable, substation, plant
  • All assets deduplicated into one nearbyPower list

5.3 What we calculate

  • Haversine distance pad → each asset; best distance along corridor samples
  • Pick nearest overall asset (tower preferred over line over SS over pole)
  • Interconnect ease: ≤0.25 km Easy · ≤2 km Easy · ≤12 km Moderate · >12 km Hard

5.4 Score calculation

StepRule
BaseLinear: 0.2 km → 10, 20 km → 0
BonusPole ≤ 350 m: +2 · Tower ≤ 2 km: +1.2 · Substation: +0.8 · Easy interconnect: +0.5
CapMaximum score 10
No data5 (neutral — not a rejection)

5.5 Contribution

Contrib = factor score × 0.10 · Shares merged power data with #6 and #7

10. Soil / SBC (Weight 8%)

10.1 What you see

  • Factor bar: Soil / SBC (open GIS + field)
  • Value: e.g. Loam · ~45% or GT-001 · 2.1 km
  • GeoTech tab: full Word report, soil tables, SBC / pile calcs
  • Soil card: GIS summary only (downloads in GeoTech tab)

10.2 What we fetch (one path wins)

  • Path A (preferred): TAMS /geotech nearest field record within ~5 km
  • Path B (fallback): ISRIC SoilGrids 2.0 — clay/sand/silt, texture, pH at depth bands

10.3 What we calculate

  • Path A: score from adopted SBC (T/m²), CBR %, design depth on file
  • Path B: USDA texture class, indicative SBC range, screening confidence ~40–48%
  • GeoTech report (separate): thickness-weighted layers, IS 6403 SBC, IS 2911 pile — NOT in /10

14. Confidence % (partial — not all 12 factors)

14.1 What you see

  • Confidence percentage on score card
  • Live data panel: "X of Y signals live"

14.2 What we calculate

  • Count 7 resolved signals: elevation, slope, road, water, settlement, grid (tower/SS), wind
  • Base 55% + (resolved ÷ 7) × 25% → range ~55–80%
  • −5% each for Photon fallback: water, settlement, grid unavailable
  • NOT counted: voltage, connection distance, land cover, soil, corridor feasibility
